Private Windows AI test

For testing sermon link imports and the private AI pilot on Windows 11.

Download 0.1.16 for Windows

Windows 11 x64. This unsigned build is for a private clean-install test. Sign in to the GitHub account with access to the private release before downloading.

To import a sermon, open Library, paste a YouTube or direct video link, and select Import link.

Private online AI test

This test uses the exact saved Wisdom & Wonder transcript.

  1. Install Commission Clips on the second PC.
  2. Open Settings, enter the private test code, then choose Use online AI and review the notice.
  3. Open the approved Wisdom & Wonder project with its saved transcript and choose Find best Shorts.
  4. Watch an online AI suggestion, edit it, and export your Short.
